# Out-of-Bounds Read/Write (OOB, 범위 밖 읽기/쓰기)

**정의**: 배열이나 버퍼의 유효한 인덱스 범위를 벗어난 위치를 읽거나 쓰는 버그다. [버퍼 오버플로우](buffer-overflow.md)는 OOB 쓰기의 한 형태이지만, OOB는 그보다 넓은 개념으로 "범위 밖 읽기"(정보 유출로 이어짐)도 포함한다.

**왜 문제가 되는가**: 범위 밖 읽기는 메모리에 있던 다른 데이터(포인터, 키, 다른 사용자의 데이터 등)를 그대로 노출시킬 수 있고, 범위 밖 쓰기는 인접한 데이터/메타데이터를 조작해 더 심각한 결과(코드 실행)로 이어질 수 있다.

**간단한 예시**:
```c
int arr[10];
int value = arr[15];   // 범위 밖 읽기 — 배열 뒤 임의의 메모리 값을 읽어옴
```
