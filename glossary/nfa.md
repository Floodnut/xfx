## NFA (Non-deterministic Finite Automaton / 비결정성 유한 오토마타)
**정의:**  
정규 표현식(Regex) 엔진의 연산 모델 중 하나로, 현재 상태에 따라 다음 단계로 이동할 수 있는 경로를 여러 개 동시에 탐색하며, 입력 문자가 매칭되는 지점에서 즉시 종료되는 방식입니다. 백트래킹(Backtracking) 기반 구현이 일반적입니다.

**보안 영향:**  
- 악성 패턴 공격 시 백트래킹이 폭발적으로 증가하여 CPU 자원 고갈 또는 무한 루프 유발 (DoS)
- 역사적 사례(CVE-2007-4772 등)에서 정규화 실패/Error 전파 경로의 불확실성으로 인해 상태 기어가 비정상적으로 동작하거나 종료되지 않는 문제 발생
- 실시간 필터링, 로그 분석, 입력 검증 등에서 성능 저하 및 서비스 중단 위험

**대응 방안:**  
- 입력 길이 제한 또는 재귀 깊이/실행 시간 제한(Timer) 적용
- 성능이 민감한 경로에서는 DFA 기반 엔진 또는 안전 검증된 정규식 라이브러리 사용
- 사용자 입력 기반 동적 Regex 생성 금지, 고정 패턴 또는 인덱싱 검색 대체
- 정규식 컴파일 시 `PCRE2`/`RE2` 등 백트래킹 제한 및 안전한 실행 모델 지원 라이브러리 채택
