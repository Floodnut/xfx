# Privilege Escalation (권한 상승)

**정의**: 낮은 권한의 사용자/프로세스가, 정상적으로는 허용되지 않는 더 높은 권한(root, SYSTEM, 다른 사용자 권한 등)을 획득하는 것이다. 이미 시스템에 어느 정도 접근권이 있는 상태에서 "더 많은 권한"을 얻는다는 점이 다른 초기 침투 취약점과 다르다.

**왜 문제가 되는가**: 대부분의 시스템은 "일반 사용자"와 "관리자"를 구분해서, 일반 사용자가 망가뜨릴 수 있는 범위를 제한해둔다. 권한 상승은 이 경계 자체를 무너뜨려서, 원래는 제한된 공격자가 시스템 전체를 장악할 수 있게 만든다.

**두 가지 형태**:
- **수직 권한 상승(vertical)**: 낮은 권한 → 더 높은 권한(예: 일반 사용자 → root)
- **수평 권한 상승(horizontal)**: 같은 권한 등급 안에서 다른 사용자의 자원에 접근(예: 사용자 A가 사용자 B의 데이터에 접근)
